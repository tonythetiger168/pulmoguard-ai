# AI + LLM + Agent + LDCT 肺癌篩檢智能平台
## 開發與臨床驗證計劃書（Proposal）

**版本**：v1.0
**日期**：2026-10-01
**時程**：30 個月
**文件性質**：內部提案用，預算與人力為初估，實際以執行單位報價為準

---

# 一、摘要

本計劃擬開發一套整合 **影像 AI（CADe/CADx）＋ 大型語言模型（LLM）＋ 智慧代理（Agent）＋ 低劑量電腦斷層（LDCT）** 的肺癌篩檢全流程智能平台，涵蓋「掃描 → 結節偵測 → 惡性表徵 → 報告生成 → 追蹤管理 → 陽性轉介」完整臨床路徑。

**三大差異化定位**：
1. 針對台灣流行病學特色——不吸菸女性肺腺癌族群與家族史族群（美國 NLST 路線覆蓋不足）
2. 全球產品空白帶——篩檢陽性後結節追蹤管理的自動化（Agent 排程編排）
3. 產出台灣第一份 AI+LDCT 成本效益研究，銜接給付與政策談判

**監管策略**：Agent 追蹤模組（無診斷宣稱）先行落地 → TFDA 軟體二級 CADe/CADx → FDA 510(k)（predicate：eyonis LCS / K251474，產品代碼 QDQ）。

# 二、背景與市場機會

## 2.1 政策面
- 台灣自 2022 年 7 月起推動「肺癌早期偵測計畫」，提供高風險族群每 2 年 1 次公費 LDCT，為全球首個針對「肺癌家族史＋重度吸菸者」雙軌補助的國家；2025 年（114 年）起擴大篩檢對象。
- 篩檢量隨政策擴大持續上升，放射科判讀人力為主要瓶頸。

## 2.2 臨床痛點
- LDCT 篩出肺結節約 95% 為良性，假陽性造成追蹤成本、侵入性檢查與受檢者心理負擔。
- 結節追蹤（Fleischner 2017 / Lung-RADS 分類後的時程管理）目前全靠人工，漏追蹤率高。
- 台灣肺腺癌患者中不吸菸、女性比例偏高，與歐美吸菸主導的風險模型不匹配。

## 2.3 競爭與時機
- 2026 年初 FDA 連續核准 RevealAI-Lung（K251769，偶發結節 CADx）與 eyonis LCS（K251474，篩檢情境 CADe/CADx），顯示審查路徑成熟；Medicare 已納入給付（0721T/0722T，約 601–700 美元）。
- 台灣 TFDA 核准件數仍少（如 LibraLung 天秤肺影，2024 年 2 月軟體二級），本土市場尚有先進者空間。
- 韓國 Coreline、中國 Infervision 已取證，台灣需加速。

# 三、產品定義與系統架構

## 3.1 產品定位
LDCT 肺癌篩檢全流程智能平台：
- **CADe**：3D 肺結節自動偵測
- **CADx**：惡性機率表徵（mSI 式相對風險分數）、侵襲性預測（AIS/MIA/IAC）
- **LLM 報告輔助**：影像發現 → 結構化報告草稿、病歷摘要、醫師 Copilot
- **Agent 追蹤管理**：結節分類 → 自動排程、召回、陽性轉介、品質稽核

## 3.2 系統分層架構

```
L4 人機協作層：PACS 整合介面、醫師審核工作台、行動通知
L3 Agent 編排層：追蹤管理 / 召回排程 / 報告品管 / 試驗招募 Agent
L2 LLM 層：本地部署醫療微調模型 + RAG（台灣肺癌指引、Fleischner、Lung-RADS）
L1 影像 AI 層：CADe（3D 偵測）、CADx（radiomics + ML）、分割量化（nnU-Net）、侵襲性分類
L0 資料層：DICOM / PACS / HIS 串接、去識別化管線、稽核 log
```

## 3.3 關鍵設計決策

| 決策點 | 方案 | 理由 |
|---|---|---|
| CADx 演算法 | Radiomics + 梯度提升（可解釋 ML） | 已有 FDA 核准先例（RevealAI-Lung），可產出特徵重要性報告，審查友善 |
| 分割模型 | nnU-Net（3D） | 醫療影像分割實務標準，少量標註即可達標 |
| LLM 部署 | 本地開源模型（醫療微調版）+ RAG | PHI 不出院、中文病歷、避免雲端 API 額外審查 |
| Agent 框架 | 可審計 workflow 引擎（如 LangGraph） | 每步可追蹤可回放，醫療場域必要 |
| 人類在環 | Agent 僅建議，臨床動作需醫師確認 | 法規安全線 |

## 3.4 安全與隱私設計
- PHI 去識別化管線（DICOM tag 清洗 + 影像 re-identification 風險檢查）
- LLM 生成內容**僅組織語言，不產生新事實**：findings 全部來自 L1 模型結構化輸出，以模板約束生成範圍
- 全系統操作留痕，符合 TFDA 軟體醫材稽核要求與醫院資安規範
- LLM 與 CADx 功能完全解耦（獨立部署、獨立 log），單一模組受審不影響整體

# 四、臨床驗證計劃

## 4.1 Phase 1：回顧性 Standalone 試驗（REALITY 模式，M6–M12）
- **設計**：多中心、回顧性、富集世代，n ≈ 1,200
- **主要終點**：AUC > 0.80
- **次要終點**：敏感度／特異度（max Youden）、陽性／陰性召回率、按結節大小／密度／吸菸狀態分層分析
- **納入**：50–80 歲，符合國健署雙軌條件；**刻意 oversampling 不吸菸女性**（台灣特色亞組）
- **排除**：純毛玻璃病灶、>30 mm、層厚 >3 mm、切片缺失、曾肺切除、胸腔內心律調節器
- **資料來源**：合作醫學中心 PACS + 國健署 LDCT 資料庫（學術合作申請）

## 4.2 Phase 2：MRMC 試驗（RELIVE 模式，M12–M18）
- **設計**：fully-crossed 多讀者多案例，10–16 位放射科醫師、480–500 案例
- **流程**：每案例間隔 28 天洗滌期讀兩次，AI 輔助與否隨機分配；讀片前 18 例訓練
- **統計框架**：Dorfman-Berbaum-Metz ANOVA，RRRC 模式，jackknife（Wilcoxon）變異數估計
- **主要假說**：AI + 醫師 優於 醫師單獨（superiority test，目標 p < 0.05）
- **特色子研究：尺寸配對（size-matched）**
  - 良性與惡性結節尺寸配對，移除尺寸共變因
  - 證明 AI 在「結節一樣大」的臨床難題下仍提供增量價值（RevealAI-Lung 的關鍵實驗設計）

## 4.3 Phase 3：前瞻性落地 + 經濟學研究（M18–M30）
- 1–2 家醫學中心前瞻性導入，收集真實世界效能與 workflow 數據
- **台灣 AI+LDCT 成本效益研究**（首份本土研究）：
  - 成本效益：每 QALY 成本（健保觀點、醫療體系觀點）
  - 預算影響模型（ISPOR 格式，供未來給付談判）
  - 假陽性減少所節省之追蹤成本估算

## 4.4 各階段成功標準（Go/No-Go）

| 階段 | 成功標準 |
|---|---|
| Phase 1 | AUC ≥ 0.85（優於預設門檻）、不吸菸女性亞組 AUC 無顯著劣化 |
| Phase 2 | 優越性檢定 p < 0.05，且 ≥70% 讀者 AUC 提升 |
| Phase 3 | 前瞻性敏感度 ≥ 0.90；成本效益 ICER 低於台灣 GDP 的 1–3 倍 |

# 五、監管路徑規劃

| 模組 | TFDA | FDA |
|---|---|---|
| Agent 追蹤管理 | 定位「流程管理軟體」，非診斷 SaMD，最快落地 | 不需 510(k) |
| CADe/CADx | 智慧醫材專案輔導 → 軟體二級取證 | 510(k)，predicate：eyonis LCS（K251474，QDQ） |
| 侵襲性／基因預測 | IRB 研究用途先行 | 二期適應症擴充 |
| LLM 報告輔助 | 定位「文書輔助工具」，避開診斷宣稱 | Locked model + PCCP 變更管理協議 |

**取證順序**：Agent 模組先行（無監管障礙、累積真實世界數據）→ TFDA CADe/CADx → FDA 510(k)。

**關鍵監管文件**：
- 軟體需求規格書（SRS）、風險管理檔（ISO 14971）、軟體生命週期（IEC 62304）、可用性工程（IEC 62366-1）
- 510(k) Summary 依 K251769／K251474 公開文件結構撰寫（幾乎可作範本）

# 十一、預期成果與 KPI

**技術成果**
- CADe 敏感度 ≥ 90%（LUNA16 基準可比性）
- CADx AUC ≥ 0.85（Phase 1）、MRMC 優越性 p < 0.05（Phase 2）
- 判讀時間縮短 ≥ 50%（對照國際產品 70% 目標，採保守估計）
- 追蹤漏失率降低 ≥ 50%（Agent 模組，前瞻驗證）

**臨床與學術成果**
- 台灣首份 AI+LDCT 成本效益研究（ISPOR 發表）
- 2–3 篇同儕審查論文（Radiology / Lancet Digital Health 級別為目標）

**監管與商業成果**
- TFDA 軟體二級取證（M24）
- FDA 510(k) 送件（M24）並於 M30 前取得
- 1 家醫學中心正式商轉、2 家以上試行合約

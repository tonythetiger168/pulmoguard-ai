# 第一部分：資料預處理與訓練管線技術規格

## 1.1 整體管線（DICOM → 模型）

```
DICOM (PACS / TCIA 下載)
   │
   ├─ L0 清洗：去識別化複查、層厚篩選（≤3mm）、FOV／矩陣統一（512×512）
   ├─ L1 重採樣：各向同性 spacing（1×1×1 mm³；z 軸層距 >2.5mm 者直接剔除不重採樣）
   ├─ L2 歸一化：HU 肺窗窗寬 (-1000, +400) → min-max 至 (0,1) 或 z-score
   ├─ L3 標籤對齊：LIDC XML → nodule mask；Tianchi mhd/raw → nrrd/nifti
   ├─ L4 切片產生：patch-based（64³ / 96³ / 128³ cube，正負樣本比 1:3）
   ├─ L5 增強：旋轉／翻轉／縮放 ±10%、gamma 校正、高斯 noise、結節中心座標微擾動
   └─ 框架：PyTorch + MONAI（醫療影像標準，含 DICOM I/O、data loader、transform）
```

## 1.2 各任務模組規格

| 模組 | 架構 | 輸入 | 輸出 | 驗證基準 |
|---|---|---|---|---|
| CADe 偵測 | 3D RetinaNet 或 nnDetection（nnU-Net 偵測版） | 全卷 CT（3D patch 滑窗） | 結節中心＋信心分數 | LUNA16 10-fold CPM ≥ 0.90 |
| 分割 | nnU-Net 3D fullres | 結節 patch | 二值 mask | LIDC 像素級子集 Dice ≥ 0.75（bounding sphere 標註特性，目標設 0.7 合理） |
| CADx 風險 | PyRadiomics（≥100 特徵）+ LightGBM／CatBoost | 結節 patch＋臨床變數 | 惡性風險分（mSI 式 0–1） | LIDC 惡性度序數二值化，AUC ≥ 0.85 |
| 假陽性削減 | 3D DenseNet-121 | candidates_V2 候選點 | 真假結節分類 | FROC 比對 LUNA16 排行榜 |
| 域適應 | 多域聯合訓練（LUNA16＋Tianchi＋LNDb）＋必要時對抗訓練 | 多域資料 | — | 跨域測試 AUC 退化 ≤ 5% |

## 1.3 關鍵工程決策

1. **統一格式**：所有資料庫一律轉 NIfTI + JSON sidecar（BIDS 風格）；DICOM 用 `dcm2niix`，Tianchi 的 mhd/raw 用 `SimpleITK` 轉換
2. **層厚策略**：訓練只收 ≤2.5 mm；NLST 早期掃描有 2.5–5 mm 者直接剔除（重採樣會模糊細節）
3. **LUNA16 無 mask 問題**：以中心座標＋直徑產生球形 label map 訓偵測器；分割任務改用 LIDC-IDRI 像素級標註（注意其分割為 bounding sphere，非精確輪廓）
4. **標註共識規則**：LIDC 4 位醫師意見不一致時，採 ≥2 位同意為 positive、4 位全否定為 negative（文獻標準做法）
5. **MLOps**：DVC（資料版本）＋ MLflow（實驗追蹤）＋ Git LFS；每筆訓練資料保留 lineage，供未來軟體文件審查使用
6. **GPU 需求**：分割 3D 模型單次全量訓練約 A100 80GB × 1–2 張 × 3–5 天；整個開發期累計約 3,000–5,000 GPU-hours（去識別後方可上雲）

# 第二部分：資料庫取得執行步驟

## 2.1 NLST 影像（TCIA／IDC，無限制開放）

**建議子集策略**（不需全抓 11.3 TB）：
- T1 期（baseline）screen-detected cancer：約 622 例
- T1 期陰性對照：隨機抽 1,500–2,000 例（配平年齡／性別／吸菸）
- 估計 2,500–2,600 studies，約 1.5–2 TB

**執行步驟**：
1. 註冊 TCIA 帳號（免費）：https://www.cancerimagingarchive.net/
2. 用 **NBIA Data Retriever** 桌面工具或命令列 `downloadmgr` 批次下載
3. 篩選條件：Collection = NLST；Study 含 "T1"；或直接匯出 TCIA manifest 圈選病例清單
4. 替代路徑（推薦）：NCI Imaging Data Commons（IDC，https://portal.imaging.datacommons.cancer.gov/）以 BigQuery SQL 圈選 cohort，再用 `s5cmd` 自 AWS 公開 bucket 拉檔案——速度快，且可對接社群衍生標註
5. 下載後跑 L0 清洗腳本（去識別複查＋層厚過濾）

## 2.2 NLST 臨床資料（CDAS 申請，M0 啟動，審查約 4–8 週）

1. 至 CDAS 註冊：https://cdas.cancer.gov/nlst/
2. 選擇資料集：NLST 臨床資料（吸菸史、包-年、家族史、篩檢結果、確診日期、存活狀態）
3. 填寫研究提案（格式見第三部分範本）
4. 注意：影像（TCIA）與臨床資料（CDAS）為**兩條獨立管道**，以 subject ID 對接串接標籤

## 2.3 其他資料庫取得（並行）

# 第三部分：CDAS 研究提案範本

## 3.1 標題
開發與驗證以低劑量電腦斷層為基礎之人工智慧肺結節惡性風險評估模型：以 NLST 資料為外部驗證

## 3.3 背景與目的（Background and Significance）
肺癌為台灣癌症死因首位。低劑量電腦斷層（LDCT）篩檢可降低高危族群肺癌死亡率，但篩出之肺結節約 95% 為良性，造成追蹤醫療資源負擔與受檢者心理壓力。近年 FDA 已核准人工智慧輔助診斷軟體（如 CADx 類產品），顯示 AI 輔助結節表徵分析之臨床價值已獲監管認可。台灣尚無本土 AI+LDCT 診斷工具與成本效益證據。本研究擬開發肺結節惡性風險評估模型，並以 NLST 資料進行獨立外部驗證，特別關注亞洲族群與不吸菸女性之適用性。

## 3.4 具體目標（Specific Aims）
1. Aim 1：以公開資料庫（LIDC-IDRI、LUNA16）開發 CADx 惡性風險模型
2. Aim 2：以 NLST 影像＋臨床資料進行外部驗證，主要終點 AUC，並按吸菸狀態、性別、結節大小分層分析
3. Aim 3：評估模型輔助放射科醫師判讀之潛在效益（後續 MRMC 研究之依據）

## 3.5 研究方法（Methods）
- **設計**：回顧性、多中心（NLST 為 33 個美國中心）外部驗證研究
- **研究對象**：NLST T1 期受試者；病例組為 screen-detected lung cancer（n≈622），對照組為 T1 陰性受試者隨機抽樣（n≈2,000，年齡／性別／吸菸配平）
- **納入／排除**：納入層厚 ≤2.5 mm 之 CT；排除純毛玻璃病灶、病灶 >30 mm、切片缺失者
- **資料需求（Data Elements）**：
  - 影像：T1 期 LDCT（自 TCIA 另行取得，subject ID 對接）
  - 臨床：年齡、性別、種族、教育程度、吸菸狀態、包-年、戒菸年數、家族肺癌史、BMI、COPD 史、篩檢輪次結果、確診日期與期別、存活狀態與追蹤時間
- **統計分析（Statistical Analysis）**：
  - 主要終點：模型 AUC（目標 >0.80），DeLong 信賴區間
  - 次要終點：敏感度／特異度（max Youden index）、NPV、依結節大小／性別／吸菸狀態分層之 AUC、校準曲線（Hosmer-Lemeshow）
  - 樣本數：依 Hanley-McNeil 法，假設 AUC 0.85、病例:對照 1:3、α=0.05、power 90%，需約 110 例癌症——本研究 622 例遠高於需求
- **隱私與倫理**：資料僅存取去識別化資料；本研究通過〔單位〕IRB 審查（審查中／核准號〔〕）；無商業利益揭露
